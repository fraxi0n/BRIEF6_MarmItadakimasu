Présentation du projet

Marmiplon est un site de recettes de cuisine. 

Développé selon l'architecture MVC (Model-View-Controller), 
l'appli n'estc pas relié a une DB (donnée fixe dans le dossier data)

techno utilisé 

front-end : html générer dans le dossier public dynamiquement grâce à EJS
js et css pour les animation 

NB :  le bouton burger a été retoucher a la main , mis sous lma forme d'une spritesheet et animé grace a un watcher dans le index.js
contrairement au autres animation moins léchée qui sont fait en css par chatGPT

back-end express et TypeScript

tsx est utiliser pour la lecture des fichier ts  


Prérequis

Installation du projet

Copie du dépôt

git clone *url du dépot*

Installation des dépendances indispensables à l'exécution du projet

npm i

Lancement de l'environnement de développement. Le watcher relance le serveur à chaque modification du fichier

npm run dev
